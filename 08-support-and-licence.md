## Support

Support is available to **verified purchasers** through RedMorrow's official channels:

- Website: [redmorrow.com](https://redmorrow.com/)
- Include your Tebex / Keymaster transaction details when opening a ticket

### Before contacting support

1. Read [05-troubleshooting.md](05-troubleshooting.md)
2. Read [06-faq.md](06-faq.md)
3. Confirm the resource starts without errors
4. Test with the native example in [02-integration.md](02-integration.md)

### Information to include in a support ticket

- Server artifact version
- Resource version (currently v1.0.0)
- Server console log when starting the resource
- F8 client console errors (if any)
- Dict and clip names you are trying to play
- Which emote system you integrate with (if applicable)
- Steps to reproduce the issue

Updates are delivered through your original purchase platform (Tebex / Keymaster). Check [07-changelog.md](07-changelog.md) for version history.
